Import from spreadsheet

Paste rows copied from the sheet (DATE, PR NUMBER, BUYER, SOLD ITEMS, QTY, UNIT PRICE, TOTAL, GRAND TOTAL, MOP). Rows without a PR number continue the receipt above. Grand totals are recalculated by the site. A PR that already exists is replaced.

Item Catalog

Saved on this device only. Items default to the glc-inventory price list. Every item also gets automatic shorthand (initials, e.g. "gte" for Gospel Tracts English; "b7" for Book 7); the shorthand column lets you set your own.
